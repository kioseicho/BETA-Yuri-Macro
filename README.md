# Yuri Macro (beta)

An Anime Dimensions macro for Roblox: Speed Raids, hourly raids, Daily Raid, Boss Rush, Auto Infinite, Auto AFK and auto-reconnect, with Roblox docked inside the macro window.

## Download and run

1. Download **[Yuri-Macro-beta.zip](Yuri-Macro-beta.zip)** (click it, then the download button).
2. Right-click the zip → **Extract All**.
3. Open the extracted `Yuri Macro` folder and run **Yuri Macro.exe**.
   Windows may warn that the app is unrecognised: click **More info → Run anyway**.
4. Open Roblox (Anime Dimensions). The macro snaps it into its game box.
5. Choose what you want on the **Dashboard** and press **Start All** (or F1).

## First-time setup

- **Auto Speed Raid → My permanent loadout:** press **Scan my characters** once (macro stopped, game visible), then pick your MAIN / ASSIST 1 / ASSIST 2.
- **Auto Raid:** pick the raid and the loadout to use.
- **Between raids:** choose Auto Dimension, Auto Infinite or Auto AFK.
- **Daily & Boss Rush page:** turn on Auto Daily Raid and/or Auto Boss Rush and pick the loadout for each (resets 00:00 UTC).
  Use **Slot 1 / 2 / 3** (the row in your Bag's loadout menu) if your loadouts have your own names.
  Boss Rush only uses the free daily entry, never your tickets.
- **Small screen or 125-150% display scaling?** The macro switches to a compact layout by itself
  (just the game; the pages open from **☰ Menu**). Change it in Settings → Roblox window → Macro layout.
  If Roblox won't shrink to the box, the macro grows the box to the smallest size Roblox accepts and remembers it.
- **Buttons not found / raids or Infinite failing on a big screen?** Stop the macro, stand in the lobby and press
  **Settings → Roblox window → Scan all buttons** once. It walks through the menus (starting nothing) and learns
  every button at your game size. Run it again if you change your screen or Windows scaling.
- Keep the game box uncovered while the macro runs, and don't turn the monitor off (it can't see the game then).

Hotkeys: **F1** start/stop · **F2** pause · **F3** emergency stop.

Screen-based only: it reads the screen and clicks/presses keys like a player. It does not read or change game memory.
